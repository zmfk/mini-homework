# 📚 极简作业提交系统 (Mini-Homework)

一个专为高校班级场景设计的轻量级作业提交与管理系统。针对传统教务系统功能冗余的问题，本项目基于 Flask + SQLite 构建，仅保留“作业发布、文件提交、名单统计与批改”等核心业务链路，旨在提供开箱即用、易于部署的轻量化解决方案。

## 核心特性

*   **多级角色权限控制**：系统内置管理员（用户管理与作业发布）、教师（文件下载与批改）、学生（学号认证提交）三类角色，实现底层数据与业务逻辑的严格隔离。
*   **文件安全拦截机制**：后端强制实施文件后缀白名单校验（仅限 PDF/DOCX）；同时集成针对 `.docx` 文件的 VBA 宏病毒特征检测，有效阻断恶意代码注入风险。
*   **异步交互与状态防护**：前端采用 AJAX 实现无刷新文件上传；内置页面卸载拦截机制，防止因误操作导致的上传中断；后台通过轮询机制实时监测新提交，动态向管理员推送通知。
*   **现代化响应式管理面板**：基于 Tailwind CSS 构建管理后台，采用三列独立滚动布局（CSS Grid + Flexbox），在桌面端与移动端均具备良好的浏览体验。
*   **存储空间优化策略**：针对云服务器存储资源受限的痛点，系统提供“清空物理文件”功能。在完成作业打包备份后，可一键清理服务器冗余文件，同时完整保留 SQLite 数据库中的提交记录与成绩名单。

## 技术栈

*   **后端框架**：Python 3 / Flask / Flask-SQLAlchemy / Flask-Login
*   **数据库**：SQLite (零配置，轻量级单文件存储)
*   **前端技术**：Tailwind CSS (CDN 引入) / 原生 JavaScript
*   **部署环境**：兼容 PythonAnywhere / Render / 通用云服务器

## 本地运行指南

1. 克隆代码仓库并进入目录：

```bash
git clone https://github.com/zmfk/mini-homework.git
cd mini-homework
```

2. 安装项目依赖：

```bash
pip install -r requirements.txt
```

3. 启动应用服务：

```bash
python app.py
```

> 系统初始化说明：首次运行应用时，程序会自动在 data/ 目录下创建 SQLite 数据库，并生成默认的管理员账号（账号：admin，密码：admin123）。
