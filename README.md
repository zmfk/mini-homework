# 📚 极简作业提交系统 (Mini-Homework)

一个专为高校班级设计的轻量级作业提交与管理系统。摒弃了传统教务系统臃肿的功能，只保留最核心的“发布任务、提交文件、批改统计”流程。采用 Flask + SQLite 构建，真正实现**开箱即用、一键云端部署**。

## ✨ 核心特性

- 👥 **三种角色隔离**：管理员（管理用户/发布作业）、老师（一键打包批改）、学生（学号即密码登录）。
- 🛡️ **安全防护机制**：
  - 强制文件后缀白名单（仅限 PDF/DOCX）。
  - 独创的 `.docx` 宏病毒（VBA）检测，阻断恶意代码注入。
- ⚡ **丝滑的交互体验**：
  - 基于 AJAX 的无刷新文件上传。
  - 上传过程中的防误关拦截。
  - 后台自动轮询新提交，右下角弹出悬浮提醒。
- 🎨 **现代化响应式 UI**：
  - 基于 Tailwind CSS 构建。
  - 后台管理看板实现“三列独立滚动”，完美适配 PC 与手机端。
- 💾 **智能数据管理**：
  - 支持按作业一键打包下载所有文件与名单。
  - 独创“清空物理文件”功能，保留成绩数据库，极大节省云端存储空间（针对免费版云服务器极度友好）。

## 🛠️ 技术栈

- **后端**：Python 3 / Flask / Flask-SQLAlchemy / Flask-Login
- **数据库**：SQLite (轻量、零配置)
- **前端**：Tailwind CSS (CDN 引入) / 原生 JavaScript
- **部署**：推荐 Render / PythonAnywhere / 阿里云等
